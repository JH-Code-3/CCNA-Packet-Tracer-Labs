# CCNA-Packet-Tracer-Labs
Hands on CCNA practice labs completed in Cisco Packet Tracer while studying with Jeremy’s IT Lab. 

Day 1 – Network Devices: Practiced identifying common network devices and understanding the basic roles of routers, switches, firewalls, servers, and end-user devices within a network.
Day 2 – Connecting Devices: Practiced connecting network devices in Cisco Packet Tracer using the appropriate Ethernet and console cables. Worked with routers, switches, and end devices while learning which interfaces and cable types are used for different network connections.
